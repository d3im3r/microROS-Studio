# Board images

`sources.json` maps each local image to its original source. Credits and source pages are displayed in the board-help catalog.

- `c3-pinout.jpg` retains the original JPEG bytes; its extension matches its format.
- `xiao-sense.webp` preserves the original 7680 × 4320 pixels with lossless WebP compression. Pixel comparison against the source PNG reported zero differences.
- `xiao-sense-preview.webp` is a 1920 × 1080 WebP preview (quality 88). The board-help image links to the full-resolution version.

The original artwork, labels and credits are preserved.
