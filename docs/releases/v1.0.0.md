ESP32 micro-ROS Template v1.0.0 es el proyecto base de firmware para usar el código generado por microROS Studio con PlatformIO, Arduino y ROS 2 Humble.

1. Descarga y extrae [esp32-microros-template.zip](https://github.com/d3im3r/microROS-Studio/releases/download/v1.0.0/esp32-microros-template.zip).
2. Configura tu programa en microROS Studio y descarga `main.cpp`.
3. Sustituye `src/main.cpp` dentro de la plantilla y conserva `MicroROSHelper.h` y las dependencias del proyecto base.
4. Comprueba que `platformio.ini` corresponda a tu placa, transporte y bibliotecas de periféricos. Studio permite habilitar su exportación desde el selector avanzado oculto en la esquina inferior derecha.
5. Configura las credenciales de red y la dirección del Agent si utilizas WiFi. Usa el mismo dominio ROS en el firmware, el Agent y las terminales ROS 2.
6. Inicia el micro-ROS Agent y compila y carga el firmware desde PlatformIO. Para Serial, cierra el monitor antes de conectar el Agent al puerto.

La aplicación web genera el código. La compilación, carga y validación con hardware se realizan localmente.

> Nota: esta descripción no incluye una verificación del contenido del ZIP.
