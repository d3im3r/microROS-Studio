# Revisión del release v1.0.0

Fuente: https://github.com/d3im3r/microROS-Studio/releases/tag/v1.0.0

Se revisó la descripción publicada y los metadatos de su adjunto. El contenido del ZIP no se inspeccionó. Solo hay un release publicado en la consulta realizada.

## Hallazgos

- La descripción presenta un repositorio de firmware, pero el repositorio que aloja el release contiene la aplicación web. Los enlaces relativos a `src/main.cpp`, `include/MicroROSHelper.h`, `examples/` y `platformio.ini` no corresponden a archivos de esta aplicación. Deben apuntar a la plantilla correcta o indicar rutas dentro del ZIP.
- El procedimiento principal pide clonar otro repositorio. Debe priorizar el adjunto `esp32-microros-template.zip`, utilizado por el botón de descarga de Studio.
- El ejemplo inicial se describe como un subscriber sin timer, pero el fragmento de configuración asigna dos handles y comenta un subscriber más un timer. Debe verificarse contra el firmware incluido.
- El ejemplo inicial usa `/led_control` con `Int32`, mientras la tabla de diagnóstico propone `/led` con `Bool`. Hay que distinguir el ejemplo inicial de los ejemplos opcionales.
- Se propone modificar `COUNT_PERIOD_MS` en `main.cpp`, aunque el firmware inicial se describe sin publisher ni timer. Esa instrucción corresponde al ejemplo publisher.
- Falta explicar el flujo de Studio: sustituir `src/main.cpp`, conservar el helper y las dependencias, y comprobar que board y transporte coincidan en PlatformIO. La exportación de `platformio.ini` está disponible en las opciones avanzadas ocultas de la esquina inferior derecha.
- El adjunto pesa 156.172.698 bytes (aproximadamente 149 MiB). Conviene inspeccionar si contiene cachés o artefactos de compilación antes de preparar una distribución más pequeña; el tamaño por sí solo no demuestra su contenido.

## Propuesta de descripción breve

ESP32 micro-ROS Template v1.0.0 es el proyecto base de firmware para usar el código generado por microROS Studio con PlatformIO, Arduino y ROS 2 Humble.

1. Descarga y extrae [esp32-microros-template.zip](https://github.com/d3im3r/microROS-Studio/releases/download/v1.0.0/esp32-microros-template.zip).
2. Configura tu programa en microROS Studio y descarga `main.cpp`.
3. Sustituye `src/main.cpp` dentro de la plantilla y conserva `MicroROSHelper.h` y las dependencias del proyecto base.
4. Comprueba que `platformio.ini` corresponda a tu placa, transporte y bibliotecas de periféricos. Studio permite habilitar su exportación desde el selector avanzado oculto en la esquina inferior derecha.
5. Configura las credenciales de red y la dirección del Agent si utilizas WiFi. Usa el mismo dominio ROS en el firmware, el Agent y las terminales ROS 2.
6. Inicia el micro-ROS Agent y compila y carga el firmware desde PlatformIO. Para Serial, cierra el monitor antes de conectar el Agent al puerto.

La aplicación web genera el código. La compilación, carga y validación con hardware se realizan localmente.

La propuesta debe contrastarse con el contenido del ZIP antes de publicarse. Esta revisión no modifica el release publicado.
